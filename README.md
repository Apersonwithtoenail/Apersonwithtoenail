# Apersonwithtoenail

Builder of small, focused Linux tools. Python, GTK, terminal apps.

## Projects

| Project | What it does |
|---------|--------------|
| **[QuillInks](https://github.com/Apersonwithtoenail/QuillInks)** | Modern text editor for terminal and desktop — GTK4 + Tkinter + Textual, tabs, splits, plugins, themes |
| **[Lyrical](https://github.com/Apersonwithtoenail/Lyrical)** | Terminal live lyrics for any MPRIS player — synced via LRCLIB |
| **[PaperRuner](https://github.com/Apersonwithtoenail/PaperRuner)** | Lightweight live wallpaper manager for Linux/X11 — xwinwrap + mpv |
| **[ACSIIGIFER](https://github.com/Apersonwithtoenail/ACSIIGIFER)** | Play GIFs and videos as colored ASCII art inside a real GTK window |
| **[linux-apps](https://github.com/Apersonwithtoenail/linux-apps)** | One-command installer for all of the above |

## Install everything

    git clone https://github.com/Apersonwithtoenail/linux-apps.git
    cd linux-apps
    ./install-all.sh

## Stack

Python · GTK3 / GTK4 · Textual · Tkinter · Bash · ffmpeg · mpv
