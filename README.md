# Apersonwithtoenail

Builder of small, focused Linux tools, hardware setups, and Python utilities.

## Desktop Apps
| Project | Stack | Description |
|---------|-------|-------------|
| **[QuillInks](https://github.com/Apersonwithtoenail/QuillInks)** | GTK4 · Tkinter · Textual | Modern text editor with three frontend editions |
| **[PaperRuner](https://github.com/Apersonwithtoenail/PaperRuner)** | GTK3 · mpv · xwinwrap | Lightweight live wallpaper manager for X11 |
| **[ACSIIGIFER](https://github.com/Apersonwithtoenail/ACSIIGIFER)** | GTK3 · chafa | Play GIFs and videos as ASCII art in a GUI |

## Terminal Tools
| Project | Stack | Description |
|---------|-------|-------------|
| **[TermFetch](https://github.com/Apersonwithtoenail/TermFetch)** | Python | System info dashboard with cava integration |
| **[Lyrical](https://github.com/Apersonwithtoenail/Lyrical)** | Python · playerctl | Live synced lyrics for any MPRIS player |
| **[Listenermerge](https://github.com/Apersonwithtoenail/Listenermerge)** | Python | Unify music history to ListenBrainz |
| **[EchoHis](https://github.com/Apersonwithtoenail/EchoHis)** | Python | Time-capsule shell history tool |
| **[Moodkonsole](https://github.com/Apersonwithtoenail/Moodkonsole)** | Python · cava | Konsole background hue shifts with music |
| **[FamiliarGoof](https://github.com/Apersonwithtoenail/FamiliarGoof)** | Python | Reactive ASCII creature for the terminal |
| **[wallflow](https://github.com/Apersonwithtoenail/wallflow)** | Python · mpv | Music-reactive live wallpaper |

## Quick Install
```bash
git clone https://github.com/Apersonwithtoenail/linux-apps.git
cd linux-apps
./install-all.sh
```
